# Lab 07 – Advanced Sorting

This lab focuses on advanced sorting algorithms in C++, covering recursive Merge Sort, Quick Sort with different pivot strategies, and LSD Radix Sort using Counting Sort.

## Topics Covered

- Merge Sort and Quick Sort
- Partitioning and Merging
- Dynamic Memory Allocation in Merge sort
- LSD Radix Sort
- Stable Counting Sort

---

## Tasks

### Task 01 – Recursive Merge Sort
- Sorts student marks and displays the array after each merge operation.

### Task 02 – Merge Sort with Comparison Counting
- Sorts product prices and displays subarrays before merging, along with total element comparisons.

### Task 03 – Dynamic Merge Sort
- Implements Merge Sort using dynamically allocated arrays and counts recursive calls, merge operations, and comparisons.

### Task 04 – Quick Sort with Last-Element Pivot
- Sorts student marks and displays pivot values, subarray boundaries, and the array after each partition.

### Task 05 – Quick Sort with First-Element Pivot
- Implements Quick Sort using the first element as pivot and counts element comparisons.

### Task 06 – Radix Sort with Counting Sort
- Sorts numeric IDs and displays frequency counts, cumulative counts, and output arrays for each digit pass.

### Task 07 – Radix Sort with Different Digit Lengths
- Sorts integers with varying numbers of digits and displays the array after each pass.

### Task 08 – LSD Radix Sort with Pass Counting
- Sorts tracking IDs and determines the total number of digit passes dynamically.

### Task 09 – Radix Sort with Detailed Tracing
- Displays intermediate arrays and the copy-back process while handling duplicate tracking IDs.

### Task 10 – Stable Radix Sort
- Sorts library accession numbers while preserving the relative order of duplicate values.

---

## Learning Outcomes

- Implement recursive Merge Sort and Quick Sort.
- Apply different pivot-selection strategies.
- Trace sorting operations and count comparisons, recursive calls, and merges.
- Manage dynamic memory in sorting algorithms.
- Implement LSD Radix Sort using stable Counting Sort.
- Analyze digit passes and handle duplicate values correctly.

> **Note:** Each task is implemented in its respective `.cpp` source file, with the original task statement included as a comment.
