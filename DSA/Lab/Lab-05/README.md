# Lab 05 – Stacks and Queues

This lab focuses on stacks and queues and their applications in C++. It covers array-based stacks, undo/redo history, queue manipulation, circular queues, and implementing a queue using two stacks.

## Topics Covered

- Stacks
- Queues
- Stack-Based Undo and Redo
- Queue Manipulation Using a Stack
- Circular Queues
- Queue Implementation Using Two Stacks

---

## Tasks

### Task 01 – Stack Operations

- Implements an array-based stack for storing and undoing editing operations.

### Task 02 – Text Editor Undo/Redo

- Implements a text editor with separate undo and redo stacks for managing editing history.

### Task 03 – Reverse First K Queue Elements

- Implements reversal of the first `K` elements of a queue using a stack.

### Task 05 – Circular Queue

- Implements an array-based circular queue for managing passenger boarding operations.

### Task 06 – Queue Using Two Stacks

- Implements a FIFO queue internally using separate incoming and outgoing stacks.

---

## Learning Outcomes

- Understand and implement stack and queue data structures.
- Apply stacks to maintain undo and redo history.
- Use a stack to selectively reverse queue elements.
- Implement circular queues with proper wrap-around handling.
- Simulate FIFO behavior using two stacks.
- Handle edge cases such as empty and full structures.


> **Note:** Task implementations are provided in their respective `.cpp` source files. The original task statements are included as comments within the source files for reference.
