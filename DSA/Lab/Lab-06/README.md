# Lab 06 – Recursion and Backtracking

This lab focuses on recursion and backtracking techniques in C++. It explores solving problems through recursive function calls and systematically searching for valid solutions by making, testing, and undoing choices.

## Topics Covered

- Recursion and Recursive Mathematical Computations
- String Processing and Digit Manipulation Using Recursion
- Backtracking and State-Space Exploration
- Graph Coloring and Constraint Satisfaction
- Pathfinding and Maze Solving
- Subset Sum and Permutation Generation
- Sudoku Solving and Word Search

---

## Tasks

### Task 01 – Reverse String Using Recursion

- Prints a string in reverse order using recursion without creating another reversed string.

### Task 02 – Print Numbers in Ascending Order

- Uses recursive calls to print numbers from `1` to `n` in ascending order.

### Task 03 – Sum of Digits

- Calculates the sum of a positive integer's digits recursively without using loops.

### Task 04 – Daily Savings Calculation

- Calculates the savings on day `n` when an initial amount of Rs. 10 doubles each day.

### Task 05 – Graph Coloring

- Assigns colors to graph vertices while ensuring that adjacent vertices have different colors.

### Task 06 – Maze Solving

- Finds a valid path through a `4 × 4` maze using backtracking, moving only right or down.

### Task 07 – Subset Sum

- Finds a subset of `{2, 3, 5, 6, 8}` whose elements sum to `9`, using each element at most once.

### Task 08 – Permutations

- Generates all possible arrangements of the characters `A`, `B`, `C`, and `D` using backtracking.

### Task 09 – Sudoku Solver

- Solves a `4 × 4` Sudoku puzzle while satisfying row, column, and box constraints.

### Task 10 – Word Search

- Determines whether the word `CAT` exists in a character grid without reusing a cell in the same path.

---

## Learning Outcomes

- Implement recursive functions with appropriate base cases.
- Break problems into smaller subproblems using recursion.
- Apply backtracking to explore alternative solutions.
- Validate constraints before accepting a choice.
- Restore previous states when a solution path fails.
- Solve recursive and combinatorial problems in C++.

> **Note:** Task implementations are provided in their respective `.cpp` source files. The original task statements are included as comments within the source files for reference.
